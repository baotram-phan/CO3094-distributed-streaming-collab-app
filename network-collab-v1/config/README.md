# Config
- `app.example.json`: cấu hình mẫu; code đọc config sẽ được viết ở giai đoạn sau.
- `users.example.json`: object trống; **không** chứa tài khoản đăng nhập.
- `users.json`: dùng script ở project cũ để tạo **hash/salt**, không commit bản local.
- Không lưu mật khẩu rõ hoặc khóa phiên UDP vào repo.
